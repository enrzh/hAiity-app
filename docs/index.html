Every check-in is a commit in your repo — it lights your real contribution graph.

Your data is stored in a private repo haiity-data in your GitHub account. hAiity is a static page — there is no server on our side, and the token never leaves this browser.

  1. Create a fine-grained token
  2. Repository access: All repositories (or create haiity-data yourself first and select only it)
  3. Permissions → Repository → Contents: Read and write and Administration: Read and write (only needed once, to create the repo — you can revoke and re-issue a Contents-only token afterwards)
