# Historical implementation plans

Dated files in this directory describe particular snapshots and decisions.
They are archived reference material, not standing instructions to redo work,
deploy, reset data or use an old build number/device ID.

Use [the engineering guide](../development.md) for current build, verification,
ownership and release rules, and [the design system](../design/haiity-ui-design-system.md)
for the existing UI contract. New execution evidence belongs in its task report.
